# Refresh an intent's Word file

Apply the `intent-sync` skill in refresh mode.

Which intent to refresh (empty means list the unlocked intents and ask): refresh $ARGUMENTS

Run steps 1–3, then "Refresh the Word file" in the `intent-bundle` skill, and stop. Nothing is pushed.
